# Changelog

All notable changes to the Universal Humanizer project will be documented in this file.

## 1.0.0 - 2026-09-10

### Added
- Initial public release of Universal Humanizer.
- Comprehensive 25-pattern detection catalog covering staging, mechanical rhythm, inflation, formulaic formatting, and chatbot residue.
- Bilingual support with tailored watchlists and before/after examples in English and Russian.
- Layer 2 editorial methodology:
  - Voice sample calibration and style adaptation.
  - Sentence length burstiness and rhythm calculation.
  - Audience targeting and grounding.
  - Empirical detail preservation and anti-hallucination constraints.
  - Read-aloud vocal test.
  - Ready-to-use Custom Instructions quick-reference block.
- Cross-platform single-command installation scripts (`install.sh`, `install.ps1`, `uninstall.sh`) supporting:
  - Google Antigravity (project and global skills/plugins)
  - Gemini CLI (extension and slash command)
  - OpenAI Codex CLI (prompts and AGENTS.md)
  - Claude Code (skill and plugin)
  - Cursor (.cursor/rules)
  - Windsurf (.windsurf/rules)
  - OpenCode (.opencode/skills)
  - Claude Desktop (ZIP release)
- Strict validation and synchronization suite (`scripts/validate-package.py`, `scripts/sync-skill.py`).
- Automated CI and Release workflows.
